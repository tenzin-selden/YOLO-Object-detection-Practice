YOLO Object Detection Practice

 ## About the Project
This is a beginner-level project exploring object detection using YOLO and the Ultralytics framework.

## Dataset
- Dataset: COCO128
- Source: Ultralytics
- Task: Object detection

## Tools and Technologies
- Python
- Google Colab
- Ultralytics YOLO
- OpenCV

## What I Learned
1. Understanding YOLO and object detection.
2. Exploring dataset images and annotation files.
3. Understanding bounding boxes and class labels.
4. Training a YOLO model.
5. Evaluating model performance.
6. Making predictions on images.
7. Extracting object classes, confidence scores, and coordinates.

## Purpose
This project was created for learning and practice as part of my journey into computer vision and deep learning.
